# صلة (Sila) - متجر الاشتراكات الرقمية المتكامل

صلة هو منصة متطورة لبيع الاشتراكات والمنتجات الرقمية، مصمم بأحدث التقنيات لضمان تجربة مستخدم فاخرة وتسليم فوري للمنتجات.

## 🚀 المميزات الرئيسية
- **تصميم RTL فاخر:** واجهة مستخدم عربية بالكامل مبنية بـ Tailwind CSS و Framer Motion.
- **تسليم فوري (Auto-Delivery):** استلام الأكواد والاشتراكات فور نجاح الدفع.
- **بوابة دفع Moyasar:** دعم كامل لـ (مدى، فيزا، Apple Pay، STC Pay).
- **إشعارات واتساب:** رسائل تلقائية للعملاء فور إتمام الطلب.
- **لوحة تحكم إدارية:** إدارة المنتجات، الطلبات، والعملاء بسهولة.
- **بنية Supabase:** قاعدة بيانات ونظام توثيق (Auth) سريع وآمن.

## 🛠️ التقنيات المستخدمة
- **Frontend:** Next.js 14, Tailwind CSS, Lucide Icons.
- **Backend:** Supabase (PostgreSQL, Auth, Edge Functions).
- **Payment:** Moyasar Web SDK.
- **Hosting:** Vercel.

## 📖 تعليمات التشغيل
1. قم بتثبيت المكتبات: `npm install`
2. أضف مفاتيح الـ API في ملف `.env.local`.
3. شغل سيرفر التطوير: `npm run dev`
